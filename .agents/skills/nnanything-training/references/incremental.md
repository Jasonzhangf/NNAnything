# 特征升级与增量策略

增量分为同结构继续拟合和结构升级后继续拟合。二者不能混称“旧权重直接继续训练”。

## 输入和参数迁移

1. 列出新增输入、新增wire、旧wire语义变化与标签变化。只增wire时不必增加DOM属性。语义改变的旧wire不能伪装为兼容新增。
2. 旧系数按层／目标／wire名称迁移，不按数组位置复制。含义未变的旧项保持数值；新增的目标wire项显式置零，使它进入可训练参数集合。缺失的键不能只是忽略，否则稀疏电路可能根本没有新参数。
3. 在输入、旧wire语义和判断规则不变的条件下，验证零初始化迁移与原模型输出一致。新增观测使null变为实际值时，另记为测量变化；不得混进零初始化兼容证明。
4. 旧样本可以从原始证据补算新属性。补不出来就保留缺测，不能补false／0。新特征在新样本中实际观测后才有相应监督。
5. 保留旧profile、原始请求及旧结果。新规则、迁移profile、拟合候选分别命名，明确采用状态。浏览器资产走既有解析入口；不建立哈希／SHA清单、冻结或额外身份包装。

兼容方向是新版读取旧样本／权重。旧运行时未必认识新增字段和wire，不能声称新权重可直接装回旧运行时；先更新支持新结构的运行时，再加载对应profile。迁移补零不等于启用新规则默认系数，也不等于已经完成新参数训练。

## 拟合与先验边界

同结构增量可从旧权重开始。结构升级先完成迁移，再拟合。旧参数可按旧值作锚定；新增参数只有初始化先验，没有历史学习证据。当前实现是损失加参数锚定的MAP式近似，不是完整后验分布，也不是自回归模型。

新增 wire 且本轮没有独立的旧训练回放时，可在训练控制配置中用 `fit.trainableWires` 只训练新增路径。记录名单并核对未入名单的旧系数未变。名单为空会冻结全部权重；省略名单才是全参数拟合。冻结系数不能替代旧黄金回归：新增非零系数遇到旧输入缺测，仍可能扩大竞争区间。先查 wire 是否按合同适用，再区分可从原始证据补测的输入、实际缺测和系数漂移；不要将 null 补成 false，也不要事后拼接权重来伪造一次冻结训练。

新系数从零开始时，先检查梯度、系数变化、开发损失和判断门限。短轮次训练后仍为unknown，不等于新参数没有参与训练。训练轮次／学习率依据开发集的收敛情况调整，不能用旧黄金或新页面留出调参，也不能直接以扩大采集代替检查优化过程。

本轮可使用新增训练样本与明确选择的旧训练回放。旧黄金和新页面留出只用于验收，不为追求指标混回训练。重复吸收同一批历史证据时，不同时声称它既作为完整先验又作为全新独立数据。若采用回放加锚定，记录它是实用正则方案，不冒称精确贝叶斯更新。

标签纠正要替换错误监督，不能追加矛盾标签使其重复计权。新增类别须复核旧other，并验证旧类回归；不是只增加类别名字。

## 回归与新场景

依次完成：迁移初始行为回归 → 基础算子及公开consumer验证 → 拟合后旧黄金回归 → 未见页面独立诊断。检查类别和judgmentStatus；other标签匹配但仍unknown不能报成高置信识别。

新页面保持不参与本轮拟合。用真实观测经过公开候选／分类workflow，记录排除、观测不足、unknown和conflict。按测量缺失、wire缺失、参数边界、标签边界、装饰叶节点等原因分组；查看代表性“新识别项”和剩余未知，防止靠全判container降低未知率。

发现退化先定位owner。证据不足时保留候选，不覆盖已采用版本。只有新增特征的实际反例表明当前输入仍不足，才进入下一轮特征扩展。
