# L2 四语义头：有限推理与增量学习实验

状态：2026-10-24 已有未集成的数值后端、递归接点与两域首次诊断拟合。CLI 首次真实 rollout 未执行读取；browser 首次有效 rollout 连续观察后预算停止。M0/M1/M2 均未完整验收，候选未采用。旧 CLI/浏览器模型的成绩不折算为四头成绩。本文是本实验的词表、四头 I/O、量化和阶段准入唯一合同；当前审计、消融清单和实施依赖见 [审计与推进计划](l2-four-head-audit-plan.md)。推理控制、领域执行和采用仍由既有 owner 维护。

## 1. 目标、边界与当前 gap

Goal：在 CLI 与浏览器两个有限技能域中，用同一四头接口学习对象关系、目标分解、状态评价、当前子目标/技能选择；通过真实反馈证伪错误假设，完成未逐题编排的目标组合或准确停止。satisfactionThreshold：原始请求的领域阈值不变；模型分数不是满足度。State：真实对象、属性、关系证据、缺测、Goal 帧、显式假设及反馈；Condition 是 Goal 对 State 的要求，不是独立于 State 的第五基础元素。Action：已启用技能的固定调用或获取知识的观察。

起点 gap：旧 CLI 的 measureQuantity 提供 qty_met 等结论，reasoning 为线性有限标签选择，曾以完整 superviseReasoning 答案集合否决预测；这些证据不足以证明新的独立语义评价或开放纠错。浏览器已有有限关系/F1/F2和输入用途实验，不能直接表达任意当前查询归属与结果评价。当前四头候选已接既有 select/derive/evaluate，但领域输入与监督存在偏差，尚未完成真实反馈恢复、正式独立评价及增量保留。候选实现不改变既有使用版本。

本轮先交实验/推理设计与量化标准。下一实施里程碑先做有限 MVP，再验持续后训练，最后才准入批量生成与词表生长设计的实际执行。不启动自然语言模型训练、不替换 L1、不新增通用 shell、不直接切换已有使用权重。初始实现复用 Handwired；若小 Encoder 后端不可用则明确 gap，先验证 MLP 候选，不复制上游或假称已支持 Transformer。

## 2. 四头及量化输出合同

四头是语义 readout 职责，不是四个 attention heads，也不是 Goal/State/Action/New State 四元素各建一个模型。可先独立 MLP，再比较共享小 Encoder+readout；首轮对照使用相同的可观察信息、候选生成器和执行入口，允许按模型声明各自编码，但不塞入语义答案。L1 权重先固定，读取其实际预测；身份、证据资格、精确测量和授权仍为确定性基础。

设 N 为当前有效对象数，K 为关系类型数，C 为本帧条件数，P 为有界分解候选数，S 为技能实例候选数。以下都是逻辑输出维度，不意味着构造全量 N² 稠密张量；可按声明候选对稀疏评分。候选召回必须单独报告，不能隐藏遗漏。

| 头 | 输入与时点 | 量化输出 | 独立监督/分母 |
| --- | --- | --- | --- |
| H_R 对象关系 | 当前对象、已测属性、角色、可观察结构及 missing mask | 每个候选 (subject,relation,object) 的 true/false/unknown logits，逻辑形状 [pairs,K,3]；返回对象引用 | 已标注关系三元组的逐类 precision/recall/F1；unknown 单列；对象改序和改名配对一致率 |
| H_D 目标分解 | 根/当前 Goal、State、H_R 实际预测、有限词表与技能描述 | P 个 typed 分解候选分数，及 supported/semantic_gap/capability_gap/unknown 四态；候选含至多4个条件、all/any 分组、数据依赖边和绑定引用 | 等价允许分解集合；合法分解命中率、必需条件召回、额外不必要条件率、语义/能力 gap 混淆矩阵 |
| H_E 状态评价 | 当前 Goal/条件、动作前期待、实际后验、H_R 关系及当前证据；初态也可评价 | 每条件 satisfied/unsatisfied/unknown/not_applicable 四态 [C,4]；附证据指针；progress 的 positive/none/unknown；被证伪的 hypothesis 指针与适用 scope | 独立事实/语义 oracle；逐状态准确率和覆盖率；假达成、错误不可能性、越范围证伪率必须单列 |
| H_A 当前选择 | 当前未决条件、H_D 候选、H_E 评价、合法技能与显式先验 | 有界 (子Goal模式,对象/参数引用,技能) 候选分数；S 个候选加 DEFER/NOOP/RETURN 三控制输出 | 允许集合而非唯一动作；合法选择命中率、错误恢复、早停与额外无用动作；RETURN 的根事实另核 |

H_D 学依赖语义，不学习循环层序、继续计数或任意执行序列。all/any 必需性不能由数组先后决定。H_A 只推进当前一步，不自由生成 shell 或新技能。对象/证据/数值参数通过输入表指针或已声明的精确运算绑定，禁止模型捏造引用或猜字节算术。

H_E 的 score 是未校准模型支持度，不直接当 satisfaction、概率或奖励。not_applicable 不是缺测的同义词；必须由不适用分支条件支持，否则 unknown。后果预测可作为 H_E 的后续 pre-action 模式，输入只能来自执行前；首个 MVP 仅要求明确的期待合同与 post-action 评价，不以四头名称冒称已训练世界模型。

首轮拟议上限：N≤16、K=8、C≤8、P≤8、S≤8、最大语义深度3、原子动作预算12、同类暂时错误最多2次尝试。超界返回 bounded_unknown，保留可继续状态，不裁掉对象后当完整输入。两个领域按同一上限测试；生产能力不因此被改限。实际资源预算须在首次训练规格中写定，不在验证后搜索到绿。

首轮数值候选：M0基线为共享两层64-hidden MLP（按对象对/候选做共享评分，非对象编号专用参数）；M1候选为2-block Encoder，d_model=64、内部attention heads=4、FFN=128，再接相同语义readout。这是可比较的初始规格，不宣称现有Handwired封装已实现attention。参数总量由实现按实际词项/输入维度统计，两个候选均≤1M可训练参数；禁止用“4头”代替参数统计。每域保持独立profile，L1参数不更新。Encoder后端不就绪则只交MLP有限结果，Encoder标UNVERIFIED，不自动换依赖或扩范围。

新四头若无合同兼容的合格权重，第一次拟合明确记预训练；不能把旧两线性单元的系数任意填入后称已继承，也不删除旧模型与回归。确有可验证的迁移映射才复用对应参数。四头初训完成并验收后，正常更新必须从该版本继续，不每批重置。新训练入口只允许train参与梯度，对混入dev/verification的请求显式拒绝并给隔离反例；评价接口单独接收只读分区，不依赖脚本作者记得过滤。

拟议损失：R和E按可确认/mask的分类交叉熵，D按允许候选集合的负log总概率并监督条件/依赖边，A按允许动作集合的负log总概率；可同时成立的关系使用分别监督，不强造唯一关系。无监督项不计loss也不填负例；各头按其有效监督数归一化，分别报告loss和梯度，首轮头权重等权。实际优化器/学习率/epoch、初始化和早停检查点由独立训练规格一次写定后才可开训；未写定即NOT_READY，不以本合同批准随意调参。数值梯度/保存回载/正式前向一致是实施验收，不能以纸面结构代替。

## 3. 有限种子词表与领域绑定

词项是参数化目标模式，不是 tokenizer token。通用壳：observe_property、locate_object、acquire_content、attain_property、obtain_task_result、establish_coverage。各项必须有类型、参数、必要证据、满足/未满足/未知及合法分解。此处英文名仅是实验语义标记，不能绕过 CLI file.property.xxx 或浏览器已有 typed Goal 合同成为新运行 API。

| 首批领域目标 | 对象与参数 | 已有入口/实施缺口 |
| --- | --- | --- |
| CLI 观察文件属性 | 当前文件、type/identity/size | entry.inspect；新模型需通过显式 adapter 绑定 |
| CLI 取得范围 | 文件、byte range、exact/up_to | file.read及读取组合；保留原始字节、覆盖、EOF和错误 |
| CLI 定位对象/确认搜索覆盖 | 显式目录、严格名称/字面匹配、one/all | 复用已交付搜索；首轮读取通过后再组合，不能计作已训练四头 |
| browser 观察属性 | scope内对象、value/rendered/expanded | 复用真实观察；不把静态DOM存在当人已看到 |
| browser 达到输入值 | 输入对象、目标值 | 现有 input 写入/读回技能；不生成 JS 操作 |
| browser 取得当前查询结果 | 当前查询引用、提交入口、结果scope | 复用 browser-search；查询归属/旧结果/缺观察的表达与模型接线需补，缺事实先报未知 |

首批 K=8 关系：in_scope、content_of、controls、associated_with、covers、current_for、can_satisfy、conflicts_with。不要求全部关系对所有对象类型有意义；typed 候选生成器只检查类型/范围兼容，不提前给语义真值。依赖边属于 H_D，不重复设同义关系头。关联与因果分开：单次共现不监督 causes；反事实样本须有受控干预，或明确只作假设。

新增需求先尝试旧词项参数和组合；现有表示确实不能区分必要结果时才提议新词项。现有可观察信息不足时补观测，不加标签掩盖。词项不产生执行权限，不存在对应技能时 capability_gap。

## 4. LLM teacher 与学生训练分工

LLM 可以生成 Goal 的候选关系、必要/替代条件、分解和期待，以及词项定义、沙箱配方、正反例；输出是 proposal。BERT/小 Encoder 是可选学生结构，不是正确标签来源。LLM 可辅助标注，来源如实记 teacher，不冒称人工或事实真值。

语法/类型/技能/权限检查过滤结构无效提案；沙箱真实回执、独立事实 oracle 和与拟合隔离的语义复核确认监督。精确算术由测量提供，语义监督由关系/条件/评价标签提供。不能让同一模型自己提案、自己评分即成为独立成功标签。存在多合法分解时用等价集合；不知道的 gold mask，不强造正确答案。

每样本保存 Goal/阈值、pre State和L1输出、候选集合、执行前期待、实际动作、post State、R/D/E/A监督、反驳证据、参数版本及最终根结果。原始内容/路径/页面身份可用于证据，不进入禁止的学生特征。禁止输入 goal_met、正确子Goal编号、fixture scenario或 teacher关系属性；实际字节数、offset、值读回等原始测量可用。身份变更、EOF等已观测事实可用，不把它们与目标的最终关系标签提前算入输入。

## 5. 推理流程修改设计

外层仍是recursive-goal的bind→run→report 3N2E，现有运行合同不变。新四头位于领域注入点内，责任图见 workflows/l2-four-head-step.graph.json（design，非新执行引擎）。每轮对象流为：接收当前Goal与真实State→编码对象并推断关系→产生有界条件/分解→评价当前条件和假设→选择当前子Goal/技能→固定调用及真实后验→重编码/后验评价与证伪→统一回执。

后验评价调用同一 H_R/H_E 合同，不新增第五个头。后验发现新的条件需求，在下一次 controller 推进时再调用 H_D/H_A；图内不加回边。已有条件和根 Goal 不因重推丢失，引用/权限/ledger/budget继续由controller拥有。原始执行错误、观察错误、条件事实和控制停止分开。

图的每个ARC须携带正常或typed停止结果，错误/已满足/缺能力/DEFER均透传到同一report。H_A不派发时execute-observe输出not_dispatched并保留原因，不调用执行器、不伪造post；evaluate-posterior此时标not_applicable，不能拿初态冒充后验。前置合同失败后下游模型也不再推理，只传回错误。该8N7E是责任图，不要求把八个普通函数分别注册为生产NodeDefinition；编译/算子绑定须在实际实现时另验。

运行时只核类型、能力、授权、证据关联及有限控制，不用 superviseReasoning 的完整答案集合替模型决定语义；完整 teacher oracle 仅在采样/评价旁路记录。错误语义选路若仍是合法只读尝试，可执行后取得反馈，不能因不同于teacher就提前全局抛错；越权、越界或无技能仍零执行拒绝。根精确事实保留确定性核验，抽象评价可以由有独立验收的 H_E 提供，不能以自评分取代独立真值。

接点映射：H_R在领域观测后的纯推断成员中运行，不替换supports的确定性合同兼容检查；H_D经adapter.derive返回typed条件；H_E经adapter.evaluate/measureProgress提供有证据的领域评价；H_A经adapter.select选已启用技能。首轮分析阶段仅形成有界候选和假设，不执行；只能报告条件可行前缀、缺事实、能力缺口或语义缺口，找不到计划不自动证明不可能。有界预测与checkpoint沿既有bounded-goal-planning接口，未启用预测时明确标未预测。

实施投影补充（Astra设计审查通过后的建议）：四头结果先由领域adapter投影，不能原样传controller。当前Selection已有selected/no_capability/defer；有技能但H_A选择DEFER时返回defer及具体缺口，不能伪装no_capability。H_D的any组先选一个有合法绑定的替代，只有被选分支进入当前required条件集合；未选分支保留为候选而非全部必需，换路仍沿既有恢复准入。H_E的not_applicable由已证明不适用的分支activation表达，不写入只接受satisfied/unsatisfied/unknown的EvaluationReceipt。NOOP只在当前事实已满足时归还；RETURN仍须独立根评价，根未满足时返回准确未满足/unknown，不伪造成功。控制器若不能表达所需续接，交唯一owner处理，不复制执行循环。

现有controller先select再derive。实验decorator在select的当前显式输入上运行R→D→E→A，使E/A获得本次实际D提议；选定技能后的derive再运行R→D并解码为绑定该技能的typed条件。二者分清提议与已生成条件，不从trace或旧预测重建当前分解。初态/后验单独评价仍运行R→E，不伪造此时尚未调用的D。当前实验拒绝续接，因为既有continuation没有模型版本引用；这不改变原recursive-goal的续接能力。

## 6. 失败证伪是核心训练对象

统一保存显式假设与 Evidence ref：假设内容、pre State、期待、失败事实、适用对象/范围/条件、被否定部分、仍未排除备选、失效条件。它属于显式 State，不从日志重建控制。

四种结论不可合并：本次动作未达期待；当前假设被否定；一条路径在当前条件下被否定；整个 Goal 已证不可能。一次无效点击只支持当前观察窗口内未见效果；部分搜索未命中不能证明不存在；exact N 在同一对象已证EOF且总量不足可支持当前要求不满足。预测失败不能自动排除技能。错误归因和范围守卫仍沿bounded-goal-planning 9.1与recursive-goal恢复合同，不重建黑名单机制。

奖励/监督区分有效证伪、错误评价、冗余重复、环境拒绝和unknown。任务最终成功不把全部尝试变正例，未执行备选不标成功。经验落盘不等于权重已学；只有后训练、回载、新任务迁移与旧回归支持才记模型学习收益。

### 6.1 未知允许尝试，不以未知代替拒绝

unknown是知识状态，不等于事实为假、操作非法或整个目标不可达。在目标/权限/技能和引用合法、effects可知且预算允许时，H_A可以选择补观察或低风险的有界探索；首轮CLI只读，浏览器仅显式授权的输入/点击/观察。已有安全前条件缺失时先取得必要事实，不用“探索”绕过授权。每次未知尝试须声明待区分的假设、要取得的观察、有限代价和停止边界；不要求先有精确概率才能观察，但不得编造信息增益。

反馈后按输入测量/关系绑定/目标分解/技能选择/执行环境/后验观察/语义评价分别记录归因候选、依据及unknown。不把环境拒绝直接罚给关系头，不因执行器成功就奖给评价头。保留pre输入、预测、实际回执与post；未知监督mask，观察确认后才补可确认标签。重复同一输入与同一刺激且无新增证据、无预声明重试理由时不算新的探索；有信息价值的否定也算知识进展。

### 6.2 确定错误与贝叶斯后验分开

确定错误形成可复核的输入/输出差异：错误发生在哪个阶段、哪项断言被反驳、当前条件和范围是什么。错误事实可确定，错误原因仍可有多个假设；不把归因猜测标成已证根因。H_R绑定输入与反馈证据，H_D提供竞争假设，H_E评价反驳与原因支持，H_A据此选择可区分假设的下一观察。无需新增第五个语义头。

贝叶斯更新面向显式归因假设H，不直接把模型logit叫后验：P(H|E,C) ∝ P(E|H,C)P(H|C)，C包含对象、状态、范围、权限与已知因素。新增因素后使用更新的条件C'和新证据重估适用假设，原始错误事实不改写。每次记录prior、证据引用、似然模型/来源、posterior及适用范围；若似然或先验尚未建立则记not_configured，不任意填概率。相关/重复反馈不当独立样本相乘；依赖不能建模时明确保留不足。

单次请求内更新假设支持度，与后台MAP式参数更新是两条不同时间尺度；现有model-evolution的MAP近似不自动算已实现本节假设后验。后验用于降序和选观察，不独自证明目标成功或永久排除技能。已证逻辑矛盾只能在其条件成立时排除；新因素实际改变该条件后可重新准入。不能为了重试而用新名字重置既有反证、预算或账本。

### 6.3 排除后继续，终了必须具名

排除记录是有条件的假设/路径限制，不是全局黑名单。当前scope内被证伪的选项不重复尝试；控制器检查其他合法候选、备选路径、补观察或有限重推。状态变化先检查旧反证是否仍适用，失效保留历史记录但不继续误排除。

| 终了类型 | 必要依据 | 根结果 |
| --- | --- | --- |
| satisfied | 根条件有当前有效证据，达到原阈值 | 达成 |
| refuted_in_scope | 当前声明范围内必要条件已证矛盾，相关可行替代均有覆盖证据 | 已证未满足，不能外推所有未知技能/范围 |
| capability_gap / semantic_gap | 已启用能力不足或词表无法表达；无已授权可推进步骤 | 未达成并返回具体缺口；不是世界上不可能 |
| evidence_exhausted | 证据仍不足，合法补观察/有界探索已用尽或不可用 | unknown |
| stalled | 按预声明n次无新增目标进展、证据或假设区分，也无新可行候选 | unknown/stalled；单次无效不自动触发 |
| budget / cancelled / unsafe_to_continue | 原控制预算、取消或不允许继续的effects/权限边界触发 | interrupted/unknown及真实错误；不包装成语义成功 |

有限终止必须由现有累计budget/retry/replan限制保证；即使不断出现新未知或新假设，也不重置总预算。已有条件已满足就归还，不能为学习奖励额外行动。停止输出保留未决条件、已排除选项、剩余能力和可恢复状态。

### 6.4 本轮新增的六个边界验收

在第7节既有配对/episode预算内安排，不靠增加样本数改变分母：①未知但合法的补观察取得新证据并继续；②确定错误却归因未知，保留多假设不误罚；③增加一个可测因素后原因后验按已声明似然更新；④原条件被实际改变后旧排除失效且可重新推理；⑤其余候选依次被有范围排除后准确终了；⑥不断产生新假设仍在原预算内停止。每域六项均须有真实/明确标注的受控证据和正确终态；未实现概率更新时第③项UNVERIFIED，不能只靠MLP分数变化计通过。另报未知转已知率、归因已确认率/弃权率、重复证据计数、错误重试率及各终了分母；未知尝试不以成功率一项评价。

## 8. 停止、规模化与词表扩展

训练前写定结构、损失、预算、数据用途与停止。相同可观测输入却要求互斥输出时先查表示/监督，不堆epoch。没有梯度、前向不一致、泄漏、假达成、旧回归或来源不独立时停止受影响门；保留原失败，不自动增训/换seed/改gold。teacher分歧按scope保留unknown并由原监督owner复核，不因模型预测反改gold。

只有M1两域通过且M2显示可持续保留与改善，才进入M3批量数据生成设计实施：以目标grammar×对象关系×前提×结果×反馈支路覆盖为主，随机名称/数值/布局为辅；按新增语义覆盖与反例贡献计数，不按文件数灌水。保留来源分区、LLM proposal→独立监督→真实证据链、关联组去重、用途变更记录和污染隔离；不新建hash包装或另一执行引擎。本轮只固定该准入与生成方法，不批准批量采集或训练。

词表生长：异常采集→判断参数/组合/观测/技能/语义缺口→LLM提出新定义与区别反例→已有词项组合不能表达的证据→沙箱受控验证→必要的输出/表示扩展→继承参数后训练+旧train重放→新来源和旧能力独立比较。新增词项不是新增权限。语义/I/O变化按设计Skill先改唯一图纸；旧embedding/读出按名迁移不保证无回归，必须实际验证。未知归类不能自动成为黄金新类。

## 10. 首轮失败后的核心设计补正

本节由 Alice 负责设计。Jenny 安排执行；领域 peer 仅承担有明确输入、输出、预算和判定的实验，不分别设计推理核心。以下是待实现合同，不把文字落盘计作功能已完成。第7节总验收不变。责任图仍复用8N7E，外层仍3N2E；后续实现须核对各 ARC 实际字段，不能新增领域控制循环。

### 10.1 分离对象资格、关系、目标条件和执行后证据

当前对象的身份/授权/引用时效属于确定性准入；对象间的语义关系由 R 学习；Goal 对事实的要求由 D/E 表达；动作执行后的来源资格只在该回执存在后评价。缺少未来回执不阻止已获准的首次动作。

CLI 未读时 `read=null`、`sourceCurrent=null` 必须保留。若目标引用、权限、类型和范围参数合法，模型可以选择 acquire/read；不得为了产生该标签，把不存在回执的 sourceCurrent 写为 true。实际错误后无回执与尚未尝试是不同状态。session revision、对象 dev/ino、内容变化分别命名；mtime/size 变化不能暗中成为根Goal新增条件。exact/up_to/零长度/端点/短读按同一读取合同解释，OS成功和Goal满足分别判定。

浏览器“已观测当前查询的结果”与“结果非空”是不同条件。空结果是否成功由请求决定。不能让采样teacher认可空结果，而运行根评价无条件要求非空。原始错误、未变化、缺测、已测不满足分别保留。

当前候选的result条件要求非空内容，这一要求保持不变：确认空结果为unsatisfied；文本未测且未显示空态只能是unknown。若另有“观察到结果状态”的Goal，须显式使用不同predicate，不能改当前gold把空结果变成功。失败读取保留attempted、调用offset/length及错误；read回执缺失不等于没有尝试，采样和运行不得采用两种投影。

### 10.2 四头的最小信息边界

| 头 | 运行单位 | 必需输入与禁止捷径 |
| --- | --- | --- |
| R | 一个具名关系的候选对象对 | relationKey、对象类型/实际L1输出、关系所需测量及mask。相同关系不因当前Goal、循环次数或无关结果变化而改变。covers等参数化关系可读明确的范围参数；不能一律删除所有参数，也不能把根目标达成标签作为关系输入 |
| D | 当前帧的有限分解候选 | 根/当前Goal、已观测State、R实际输出、技能描述。输出带引用的条件模板、all/any及依赖；“input/read”等标签只是模板引用，不能直接冒称已学任意分解 |
| E | 一个具名条件与其证据 | predicate、实际状态、相关R输出和执行前期待；分别输出四态。初态与后态明确区分。证据范围与资格校验不会被模型分数替代 |

各域显式列每种关系/条件依赖的字段，encoder与采样、运行共用。共享评分器按对象对/条件/候选调用；对象引用只作绑定，不进入数值捷径。上游预测只编码一次。E单独评价与选择阶段允许不同上游可用mask，但必须训练和验证两种调用形状。D的selection提案与skill-bound derive须有明确一致性关系，不得在两次调用间偷换目标或样本口径。

精确事实检查器保障根Goal真实成立；E仍须单独接受独立评价，并以实际输出影响下一步选择。系统根成功、E预测正确、正确停止分别计分。移除E输入后的行为对照可检验它是否有贡献；不能让精确检查器替E拿成绩。

### 10.3 一次决策与反馈回路

每次处理当前Goal帧：读取真实State及证据资格 → R关系 → D有界条件候选 → E当前条件 → A一步选择和期待 → 固定调用 → 安全后验观察 → R/E复评 → 归还条件事实和反馈。下一步仍由原controller驱动，不训练循环层序。

执行前期待至少含：待检验条件、成功/失败/无变化/缺测的可观测特征、观察方式、适用对象与scope、可区分假设及本次代价。不得事后把实际结果改写为原期待。失败仅证明这次发生了什么；未确认归因时保留unknown，不能惩罚所有候选或永久排除技能。

后验内核接入同一显式决策状态：假设、先验、证据、适用范围、重复证据记录、已确认排除与累计成本。只有声明了合法似然模型才做贝叶斯更新；未配置时返回not_configured，继续合法的非概率观察，不能以softmax当似然。请求内假设后验与请求间权重后训练分开。

有证据的排除进入既有 planning.attributeFailure/限制合同；未配置或unknown时沿既有停止边界，不另造“排除”旁路。变更scope/对象/条件后重新核对旧排除，保留历史。checkpoint恢复不回滚外界真实状态，不重置预算，不自动重放有副作用动作。新wrapper当前不支持continuation时明确拒绝，不宣称已具备跨请求恢复。

终了由原controller保证：根证据满足则完成；合法选项已穷尽且证据充分才报告范围内无可行路；证据不足报告unknown；预算/取消为控制停止并保留根事实。连续无信息收益的同动作必须受有限重试控制，不能靠新子Goal编号制造进展。新的假设、子Goal或checkpoint不重置累计限制。

进展以具名事实的变化判断，例如缺测变实测、一个条件变满足、假设被有效区分；不是stateId、尝试次数或重复receipt的增加。外部观察失败时仍返回原执行错误和单独观察错误，不能让二次观察异常遮掉第一次失败。

### 10.4 学习闭环与泛化判据

先修正可观察输入、监督和实际接口，再拟合。收集当前学生在TRAIN沙箱实际访问的初态、中间态、错误态和恢复态，由离线teacher提出监督、独立事实确认后加入TRAIN；保留旧TRAIN重放并从现有profile继续。teacher不进入正式运行，不代走正确路线。

首次不完整预训练的修补仍属于预训练完善，不改称M2。表示确需改动时按字段/标签迁移兼容参数；如无法保持原函数，明确标结构迁移并测旧能力，不能静默重置。经事实证实的错误监督须保留原记录、原因与更正记录，不要求保留错误标签，也不能依据学生预测改gold。

泛化分开验证：同语义新参数、未见来源布局、已知原语的新组合、错误后的换路、两批后训练后的旧知识保留。有限实验不能证明任意无限样本正确；能证明的是在声明范围内，学生使用稳定关系而非对象编号或固定序列，且新组合可达。先M1，再M2，再词表生长；更换Encoder不是当前缺口的默认解法。

### 10.5 首个可实现切片的输入与条件映射

不新增第五个学习头。一次决策显式传入根Goal与当前Goal、已测对象表、证据表、有限候选技能、条件表、期待与反馈、控制器剩余预算，以及capture的profile。引用保留在typed表中，数值模型只返回候选索引/标签；解码不查日志、不查teacher、不更换对象目标。

| 概念 | 必须区分的字段/含义 |
| --- | --- |
| 绑定资格 | 对象ref、观测时dev/ino或DOM引用、session/scope revision、授权；事实注明测量时点，不承诺未来不变化 |
| 调用事实 | operation、typed参数、attempted、实际run引用；执行失败仍保留这些事实 |
| 观察事实 | 实际回执或null、观察错误、来源对象、关联请求、已测值与mask；不得预填未来字段 |
| 关系候选 | subjectRef、relationKey、objectRef/typed参数、可用证据；R给true/false/unknown |
| 条件候选 | predicate及绑定、all/any、dependsOn、必要证据；D选有限合法模板并报告supported/gap/unknown，不用动作名称代替含义 |
| 决策期待 | 所选子Goal/技能、预期可观察成功/失败/无变化/未知、观察方法及待区分假设；执行前形成 |
| 反馈 | 原始调用/观察错误、E条件评价、可确认归因或unknown、适用范围、实际新事实；先验调整不改原根Goal |

CLI首个根Goal沿file.property读取合同绑定对象及offset/length/mode。条件分别是binding_usable、read_receipt_observed、requested_range_obtained。binding_usable是当前安全资格；read_receipt_observed在执行前未满足并不阻止read；requested_range_obtained由当前合法回执的范围、数量和结束事实评价。exact的长度0在合法请求下允许0字节；up_to依据已观察EOF和数量而非隐含offset≤size前提，仍须用公开OS反例确认与已有合同一致。未知类型/资格可走已注册inspect；原根固定identity时，文件被替换不能偷偷重绑新对象当成功。按路径定位的目标才可按其原合同重新绑定。

Browser首个非空搜索Goal保留input_value_matches、current_query_submitted、post_state_observed、current_result_nonempty四个不同predicate。D返回必要条件及依赖，A据当前未决条件选INPUT/SUBMIT/OBSERVE。旧结果不能成为必须先消失才能输入/提交的前提；等待已提交查询与尚未提交是不同情况。observation只证明当前查询的后验已取得，不证明非空。input/submission/observation/result在teacher、当前子Goal、投影和精确事实检查中一一对应；任何缺映射都显式拒绝，不统一落入result。

子条件的all/any与依赖是声明语义，不是强制动作序列。已满足条件可跳过；动作后事实改变时重评。最初只绑定已知对象的实验不能宣称完成自动对象发现、八种关系全覆盖或任意词表分解。后续候选生成/关系扩展仍须通过第7节M0/M1，不以本切片降低总验收。
