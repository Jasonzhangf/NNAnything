# 第一层训练与增量实验记录

2026-10-17。目标是验证手写分层 wire 能否训练、保存、回载，并比较固定权重在新页面上的表现。当前分类器识别基础种类，尚未识别帖子、作者、广告等第二层业务语义。本文记录已运行结果，不表示站点总体准确率。

## 顺序 MAP 式增量更新

用户在初次未见评估后明确要求检验贝叶斯式后验与增量训练。原候选和初次报告保持独立保存。本轮仍复用原六节点 workflow，无新引擎或 DAG 回边。

以首轮权重 w₀ 为先验中心，在既有稀疏连线上求新的点估计：

```text
最小化：新增训练样本的平均代理损失 + λ/2 × Σ(w − w₀)²
固定：25 epochs，learningRate=0.01，λ=0.01，原阈值与 wire 路径不变
```

这可解释为固定各向同性高斯锚点与代理似然的 MAP 式近似。没有保存后验方差、协方差或证据精度，也没有计算类别后验概率。不是完整顺序贝叶斯学习，不能把分类分数当校准概率。由于使用平均代理损失，批量大小变化也不自动对应严格贝叶斯证据量。

只有新增知乎 59 个确认样本产生梯度。同站搜索/回答及共享背景一起分组。微博72和小红书68留出，未参与本轮拟合。原158个黄金样本仅回归，不重复加入本轮似然。这样避免将同一批旧证据同时编码为先验又重复回放。旧数据回放重拟合是另一种训练方案，不能与该顺序近似混为一谈。

| 比较集 | 数量 | 首轮候选 | 增量候选 | 修复 | 退化 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 新知乎训练 | 59 | 52 | 59 | 7 | 0 |
| 新微博与小红书留出 | 140 | 132 | 139 | 7 | 0 |
| 新页面全部确认项 | 199 | 184 | 198 | 14 | 0 |
| 原黄金回归 | 158 | 158 | 158 | 0 | 0 |

损失从0.0198361降至0.00565365。剩余1个微博搜索布局容器为unknown：其2个子元素中只有1个有正面积，未激活多子布局wire，增量后大类分数仅0.2884。未对该结果调参或二次追分。知乎结果属于训练内效果；微博/小红书属于未参与本轮拟合的对照。它们的首次预测此前已经查看，因此不是再次盲测。相同页面共享组件且样本量很小，尚不能给出主流网站泛化保证。
