# 编程任务的第二层语义：证据获取与确定操作组合

状态：Alice 需求与组合合同设计，2026-10-28；未实现、未训练，非运行 API。依据用户本轮明确分工，研究员负责 P1–P6 基础设计，Alice 审批；本二层设计由 Alice 负责。基础训练优先，本文不启动二层拟合。

## 1. 依据、目标与边界

复用 [原操作目录](cli-semantic-operations.md)、[属性合同](cli-filesystem-semantics.md)、[P1–P6 训练设计](cli-property-training-design.md)、[固定调用](cli-command-design.md)。已有搜索后读取的有限证据沿 [原设计](cli-search-read-learning.md)保留，旧预算、旧手工遍历不能覆盖本轮正常命令用法。

用户提供结构化范围、精确条件和要求的结果。系统负责取得证据、组合已验收能力、选择必要下一步并判断任务是否完成。简单确定写操作可用：目标、字节或属性值必须由调用者给出。当前不做 multi edit、跨文件批量修改、生成代码、理解代码含义或自主决定修改内容。读取代码与理解代码分别计能力；字面命中不能报告为编译器级引用或调用关系。

只读任务不执行写操作。写任务仅沿本次显式授权及基础语义已有 effects 执行。命令本身能完成的递归、过滤、批量 needle 查找等由固定命令完成，不训练逐目录循环，也不为制造组合强拆一步操作。

## 2. 编程中需要的组合目标

下表是需求设计目录，不是能力通过清单。P 分组不改变原义；搜索复用已验收实验，但正式接入与多输入支持须独立确认。

| 二层目标 | 调用者明确提供 | 基础依赖 | 交付与可判定终点 |
| --- | --- | --- | --- |
| 范围内多条件定位 | 搜索根、精确名称/后缀、多个字面 needle、AND/OR、one/all | P1/P2/P3 + 命令级搜索 | 返回匹配文件和每项条件证据；all/无匹配须完整覆盖，one 取得一个合格结果即可 |
| 定位后取得指定片段 | 上述定位条件、行/字节范围或命中前后行数 | P1/P2/P3/P5 + 搜索/原生读取 | 路径、实际片段与位置、覆盖或短读原因；不总结代码含义 |
| 文件属性与对象关系核查 | 一个或两个路径、需要的类型/链接/同对象关系 | P1/P2/P3 | 区分词法路径、物理路径、同名、硬链接同对象和字节相同；未知不当不存在 |
| 文件/范围一致性核查 | 两个明确文件引用及 whole/range 比较要求 | P1/P2/P5 | 相等、不等或证据不足，附读取范围；前缀相同不等于全文相同 |
| 显式清单完整性核查 | 根目录、明确文件清单、每项存在/类型/可读条件 | P1/P2/P3/P5 | 每项证据、缺失和未知分列；仅全部必要条件成立时完成，不凭文件名推用途 |
| 单目标确定内容保存 | 已定路径/父目录、明确 Bytes、create-new 或 replace | P1/P2/P4/P5 | 新建或替换后实际字节符合要求；目标冲突不自动覆盖；不生成内容 |
| 单目标确定追加/长度调整 | 已绑定文件、明确追加 Bytes 或目标长度 | P2/P5 | 追加保留原前缀，截断/扩展符合原语合同；一次追加不能因后验未知而盲重放 |
| 单条目搬移/复制/链接 | 明确源与目标、明确操作语义 | P1/P2/P4/P5 | 移动检查源消失及目标正确；复制检查源保留与目标字节；链接检查原合同关系，不互相 fallback |
| 单目标属性设置并核验 | 已绑定目标、明确 mode/uid/gid/atime/mtime | P2/P6 | 实际属性与声明值一致；拒权、精度差异及其他实际变化单列，不提权 |

第一批二层设计优先闭合“多条件定位”和“定位后取片段”，再做一致性/清单核查。简单写组合只等待各自基础语义验收，不以它们阻塞只读组合。目录树批量变更、自动修复、自动运行构建/测试、Git 提交不在本轮二层目录。

## 3. 第一批精确组合合同

以下字段是设计表达，尚未注册公开 schema。根 Goal 仍沿既有 file.property 条件及通用组合合同，不创造另一类核心 Goal。

### 3.1 多条件定位

输入包含 scopes、nameEquals 或 suffixEquals、literalNeedles、needleLogic=all/any、needleScope=file/line、resultMode=one/all，以及显式隐藏文件/忽略文件/链接策略。路径与字符原样传递；大小写默认精确。空 needle 集合只表示无内容约束，不能偷换为匹配空字符串。空字符串 needle 不在首批支持集，明确拒绝。

AND 默认不能省略作用域：file 表示多个字符串可在同一文件不同位置，line 表示必须在同一行。OR 表示满足任一字面条件。候选文件同时满足名称/后缀、类型及声明的内容条件。多个根的结果按来源保留；对象别名去重需要真实身份，路径不同不能自行并为同一对象。

正常调用优先一个支持递归的命令。若命令的多 needle 是 OR，而目标是 file-level AND，固定适配器必须保存逐 needle 命中证据并做确定性集合交集，不能将 OR 回执冒充 AND。可行时一次扫描获取所有 needle 的位置；适配器若不能提供归属证据，则此组合未就绪，不临时拆成模型逐目录扫描。

one 不要求证明所有范围已搜索完，但必须证明返回项满足全部条件。all 必须报告范围覆盖。完整覆盖后的空集是已完成查询，matched=false；如果根条件是“至少存在一个匹配”，该条件为 unmet。扫描被拒、截断或超时且不能证明覆盖时，不能声称无匹配或返回完整 all。

### 3.2 定位后取得片段

输入在定位合同上增加 extraction：明确 byteRange、head/tail 行数或 matchContext 前后行数。实际源文件内容作为不透明字节交付；固定解码、行边界和位置换算由适配器完成，不计作模型理解。无新 parser 合同就不接受“读取某个函数”等需要语法识别的请求。

优先复用搜索命令已取得且满足要求的上下文，避免重复读取。否则绑定真实命中对象后按要求读取。所有片段保留对象来源、位置和实际覆盖。搜索后对象失效不得将新文件内容嫁接为旧命中证据；可在原范围重新观测，只有重新建立匹配依据后才继续。

head/tail 让原生命令处理首尾定位；短文件正常返回现有行。读取满足度按请求合同判断，不能强制恰有 N 行；精确字节等值目标与 up-to 读取不同。范围长度由确定性规则计算，不让网络猜 offset。

## 4. 简单写的组合合同

以单文件保存为代表：Goal 是指定目标内容等于调用方 Bytes，阈值 100。State 包括当前是否存在、类型、身份、所需父目录及后验可用性。Action 从 P4/P5 已注册操作选择；内容由调用者提供，网络只决定必要操作及参数引用。

- create-new：目标必须确认不存在，父目录必须满足原语条件；创建并写入后读回。若基础原语可在一次固定调用完成同一对外语义，复用它，不为训练拆步。
- replace：只替换明确的已有普通文件。调用方若提供预期旧字节，则先验证；不符时停止该写，不擅自更新预期。
- 已有可信、适用的内容相等证据可直接完成，避免无意义写入。
- 写执行成功而后验缺失：结果保持 unknown，保留实际副作用；不能自动再次追加或把整个操作当从未执行。
- 写入后的内容与目标不同：根目标未达成，保留失败及实际内容证据，不隐藏部分写入、不自动回滚。

明确不支持 multi edit：本批每请求最多一个内容修改目标、一个明确内容操作，不接受批量 patch 列表或跨文件事务。一次创建后写入再核验是一个目标的必要阶段，不属于模型生成多个编辑点。移动/复制/链接虽涉及源和目标，仍只接受一个明确对象对，不升级为目录树批量操作。

## 5. 推理职责与 DAG

本轮已读取 l2-four-head-step.graph.json（8N7E，design）和 recursive-goal.graph.json（3N2E）。两者单入口、单出口，责任路径闭合。复用其绑定→关系→条件分解→当前评价→选择及期待→真实执行观测→后验评价→归还结果路径；跨步由现有 controller 接续，不另写循环。本文不修改拓扑；新的领域绑定尚未实现，不能把拓扑闭合当可运行证据。

二层输出是必要条件、合法的已注册技能引用、执行前结果期待和是否仍缺证据。P1–P6 共享策略继续拥有基础命令选择；二层不新增同义命令 selector，不复制基础权重。R/D/E/A 仅作为职责划分；正式模型头和输入维度需在对应详细切片中证明必要性，本文不凭目录数预设参数。

确定性部分：字面匹配、集合交并、身份、权限、范围计算、命令/argv、固定协议解析、精确内容比较和根事实判定。可学习部分：在有多个合法能力或缺失条件时选择需要的观测/技能，判断下一步与终止的语义关系。若整个切片已经由固定规则唯一决定且没有学习缺口，记录确定性完成，不虚设 MLP 或宣称训练成功。

执行前期待保存为独立预测，如“取得覆盖证据”“获得指定片段”“目标字节满足”。执行后仅由真实回执产生 State。期待与实际一致/不一致/未知分别记录；不一致定位到模型选择、绑定、执行或观测，不能直接把所有失败作为负例或触发写重放。

## 6. 评价、数据与就绪条件

基础层、组合模型选择、真实工具结果、根任务达成分别报告。训练、开发、独立验证按关联来源分区；旧反例只作已知回归。原始失败、实际命令、耗时和每头计时保留。常规执行测试只设外部 timeout；调用方显式预算耗尽如实报告，不改计数追通过。

必需区分反例：
- 同名不同父目录；名称命中但类型错误；路径别名与同对象差异。
- 两 needle 分别命中不同文件；同文件不同行；OR 有一项而 AND 不成立。
- 完整无匹配与扫描未完成；one 已找到与 all 尚不完整。
- 已有上下文足够与需要补读；短文件、空文件、读取前对象变更。
- 内容已相等无需写；create-new 目标已存在；写后验未知；重复追加风险。

独立验收对声明支持的每类报告支持数、选择正确率、根目标达成、假成功、遗漏与额外调用。必要精确事实与授权边界零错误；不能靠平均分抵消误写或假成功。组合模型阈值及固定训练配方在详细切片准入前给定，此概要不授权拟合。

当前缺口：多根 all、逐 needle 来源和覆盖联合回执、上下文提取正式绑定、各写原语及可回载策略的实际可用性须逐项核对。只有相关基础能力和数据已验收，才准备该二层训练合同。文件存在、设计已落盘和已有搜索有限成绩均不替代这些证据。
