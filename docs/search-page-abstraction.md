# 搜索页面抽象与参数化样本 v0.2-design

本合同维护跨页面搜索的最小抽象、样本配置及后续训练接点。可交互环境为`playground/browser/search-fixture/`，它是被观察的合成应用，不是搜索runner、DOM解析器或已训练模型。当前不修改`lib/`、权重和基础分类词表。配置能表达不同页面，只证明表示兼容，不能据此宣称模型已跨站泛化。

## 观察依据

2026-10-20本轮在同一Ego浏览器空间，通过原生键鼠实际查询微博“露营”、Google/Bing“camping checklist”。微博显示正文、图集、视频、用户旁栏、话题及智搜内容；Google包含图片区组与网页标题、来源、时间、摘要、分页；Bing包含带引用的分节回答、网页及子链接。搜索结果可能是多个不同集合，不要求每项都有独立标题或链接。

小红书本轮可见推荐瀑布，输入查询后仍为推荐页并出现登录提示，不能当作搜索成功。知乎本轮为登录页。两站现有本地历史材料可作结构线索：小红书历史搜索含笔记/用户入口及AI总结，知乎历史材料含问题/回答摘要、作者、赞同和展开。知乎历史document标题含查询，但若干内容与查询不同，故查询关联未经本轮确认，不能作为成功gold。历史材料均为顶层文档，裁剪及候选资格未完整测量；它们已经看过，不再当新独立集。

随后按历史真实搜索URL直接导航复核：小红书仍回到推荐页和登录遮罩；知乎出现搜索外壳、未搜到内容文案与登录面板并存。该并存状态不能证明真实无匹配，仍保留访问/覆盖不足。对应本地记录为p1/p2-direct-settled.local.json；没有绕过登录或调用私有API。

随后按用户要求改用可见Chrome原生窗口。登录后实际读回输入value为“露营”，Enter后标题和搜索路径对应新查询，截图确认笔记瀑布与独立AI总结栏同时呈现，还有笔记/用户入口、筛选/地域条件、流内相关查询及图文/视频/直播入口。期间曾误提交推荐词，读回不符后纠正，不能将该次记为“露营”成功。输入placeholder可保留旧推荐词，不等于当前value。Chrome现场验证是Agent演示，不是项目学生/runner验收；知乎限制仍未解除。

原始页面与截图仅保留在`/Volumes/Intel/playground/nnanything-runs/search-results-fixture-20261020/`，Chrome补证见chrome-followup.md。入仓内容、作者名称和SVG均原创。嵌套引用、无效点击、延迟/空/错误/阻断等边界包含合成扩展，不冒称全部来自本轮现场。历史登录限制保留为当时事实，不覆盖后来的登录后证据。

## 四元素与对象结构

Goal是在显式范围内获取属于已提交查询、满足内容及覆盖条件的结果。精确子目标满足度为100，明确不满足为0，证据不足为null；根目标沿实际任务阈值和必要条件判断，不将子分数相加。State包含输入草稿、已提交查询、结果所属查询、加载/错误/阻断、当前批次及覆盖、文档/观测版本与关系证据。Action为当前输入、提交、读取、翻页、展开或重试。每步New State须重新观测，动作已发出不等于目标达成。

| 对象 | 稳定结构 | 关键边界 |
| --- | --- | --- |
| SearchScope | 编辑宿主、提交/过滤控制、结果集合及关联 | 旁边的评论框或备注不是查询宿主 |
| QueryState | draft、submitted、resultsFor、requestRevision，以及请求/显示/访问状态 | 输入相等不证明提交，旧结果不能归新查询；空文案可与登录阻断并存 |
| Collection | 集合引用、当前批次、顺序、hasMore、可见/已检查范围 | 当前批次完成不等于全部覆盖；条数不是全量完成证明 |
| ResultItem | 可独立读取的内容实体、可选字段和嵌套对象 | 不固定为某站帖子或标题摘要链接三元组 |
| ContentField | title/body/source/author/time/media/metric等可选槽位 | 正文可以没有标题；头像不等于正文图片；缺失不等于未观测 |
| Relation | owned、nested、citation、control，以及查询/集合关联 | DOM包含不是归属真值，引用来源不重复算搜索结果 |
| Evidence | document/observation/revision、来源与适用范围、known/unknown/conflict | 历史、预测、fixture内部真值不能冒充当前实际证据 |

未来标准观测值用`known(value) / unknown(reason) / conflict(refs)`显式区分。字段确实不存在可为known(absent)，未测不得补false或零。稳定接口不保证所有新语义都可表示；有整类场景无法区分时，先提供缺失表示的反例，再按模型演进合同修订受影响观测或wire。

请求状态、结果显示和访问条件分别观测。例如请求可为loading/settled/error/unknown；显示可为none/old/current/empty/partial/unknown；访问可为available/login_required/challenge/unknown。不能用一个互斥status枚举覆盖所有事实。fixture scenario只配置刺激方式，不作为学生的实际状态真值；单条“无结果”文字不足以压过登录或覆盖缺口。

## 参数结构与同一核心

`cases.mjs`声明场景与配置，`page.mjs`的`renderPage(profile,scenario)`共享所有页面逻辑，`server.mjs`只选择配置，不按站点名切换解析器。参数分为：

- 内容与关系：groups/items/fields/children，主集合、旁栏、引用及原创显示内容。
- 表示：columns/maxWidth/cardBorder/fieldOrder/wrapperDepth及input.tag/type。
- 场景：normal/delayed/empty/error/blocked/ineffective，确定性查询延迟、两页批次和恢复行为。

五配置分别表达社交流、媒体瀑布、问题/回答、网页与图片区组、直接回答/引用/网页混合。核心完成后再增紧凑配置，复用现有维度；若必须改核心才能渲染，应记录具体缺失维度，不再称其为无需改核心的新增配置。此配置留出不是模型独立测试集；这些页面仍来自同一个实现家族。

fixture的字段role、item key和结构属于应用源/teacher，不能作为学生预测输入。页面仅呈现正常内容与自然HTML语义，不暴露teacher关系、expected ids、data-gold或内部profile。学生必须从实际观测和许可特征投影判断。场景选择区与搜索任务区隔离；case/profile身份、原始class/id/URL、账号名及固定位置不得作为数值答案线索。

## 交互与效果

输入草稿不改变旧结果归属；提交后显示加载及新查询，旧结果仍标旧查询。慢A、快B的迟到回调不能覆盖B。空结果、未提交、加载、错误与登录阻断分别显示；错误可原生重试，阻断保留输入但不模拟登录。主入口无效时真实点击不改变状态，备用入口可完成提交。两页分页属于明确的合成范围，新查询重置到第一页。相邻备注不变。

本版的内容响应按配置固定，不实现语义检索。`resultsFor`只表示此批应用响应属于哪次实际提交，不能据此推出内容相关性。训练/evaluator还须分别检查内容条件；可含不匹配结果这一事实不能被根目标标签掩盖。

页面自己的事件处理正常响应真实键鼠。Agent不得调用页面内部函数、JS设值或fetch替代动作。媒体是原创本地占位；视频仅封面预览，不证明播放。textarea与search input可在fixture中操作，但现有InputTextValue首轮合同仅普通text input且仍未实现，不能据此宣称项目学生已支持新宿主。

## 可训练边界

页面生成参数不等于模型权重。以下四个训练slot可复用统一infer/train生命周期；本轮只固定语义输入/输出，不注册模型、不虚构矩阵规模，不拟合。

| Slot | 许可输入及候选wire | 学习输出与反例 |
| --- | --- | --- |
| 内容角色 | L1实际结果、局部结构、文本/媒体形状、几何及known/value | result与field角色或unknown；正文/旁栏、标题缺失、头像/媒体对照 |
| 对象关系 | 候选对、显式关联、局部祖先/邻接、范围/引用证据及known/value | owned/nested/citation/control；包含但不归属、相同名字不同对象 |
| 查询关联 | 观察到的编辑/提交/结果范围与版本变化、查询比较事实 | edits/submits/results_for或DEFER；输入正确但未提交、推荐混入、旧结果同词 |
| 当前选择 | typed Goal、实际State、关系预测、启用技能和当前能力事实 | 当前动作/对象引用、NOOP/DEFER；歧义、缺测、旧引用、点击无效 |

语义模块可由手写teacher建立初始样本，经独立泛化验证后形成显式权重，再用后验样本后训练。权限、真实验收、预算和账本不学习。权重候选热重载和对照沿[有界决策合同](bounded-planning-decision.md)，训练与无回归采用沿[模型演进](model-evolution.md)；本轮不自动采用。

## 逐步搜索闭环与观察拆解

本节沿[通用逐步观察合同](design.md#114-所有行为的观测反馈义务设计合同)。目标是每步都有真实反馈、错误可准确返回且不跳过必要条件的流程，不能保证外站可用、内容真实或任何查询都有答案。学习型识别仍可能误判；未知必须可拒绝，实际能力须独立评价。搜索不是固定动作列表：初态已满足则结束，前提未满足只衍生当前必要子Goal，条件失效则从真实State重新选择。根Goal、查询绑定、阈值和内容/覆盖要求不丢失。

### 动作各自的观察方式

每行是可独立验证的当前步骤。使用同一operation-episode的识别/决策/执行/重观测/验证责任链；表内跨步依赖交既有递归controller，不新增浏览器执行引擎或单次DAG回边。以下均为待实现搜索绑定，非新增可调用API。

| 当前子Goal / Action | 本步观察方式与最小事实 | 达成依据与下一步可用条件 | 必须保留的反例/失败 |
| --- | --- | --- | --- |
| 绑定搜索范围与输入宿主 / 读取、定位 | 当前可感知范围、宿主类型/可编辑事实、label/用途、提交和结果scope的关联 | 当前唯一且适用的逻辑宿主及证据；已绑定对象才能输入 | 相邻评论/备注、模态覆盖、歧义、未支持宿主；不能只凭input类别选择 |
| 将查询写入宿主 / 原生文字替换或NOOP | 在新观测中重绑同一宿主，读实际value/可编辑内容，确认未误写本次受影响的独立字段；需要时观察焦点/输入错误 | 按typed查询的明确比较规则相等；只完成写入子Goal，不证明已提交 | typeText未生效、placeholder相等而value不同、中文输入未提交、写入错误对象、被截断/重置、宿主重建 |
| 使当前查询被提交 / Enter或明确提交控件 | 核对最新输入，提交后观察请求反馈、查询/范围关联、导航或结果版本，以及错误/访问状态 | 有实际提交/响应关联证据；没有可观察的独立提交信号时暂记未知，后续对应响应可共同证明 | 输入已相等但未提交、默认推荐词被提交、无效点击、旧页仍有结果；不能强制所有站都提供URL/加载标志 |
| 取得当前响应 / 有界等待、读取 | 请求、显示、访问状态分别观察；当前查询/过滤条件与响应关联、内容是否真正可读；AI与主结果分别观察 | 当前结果/明确空结果有足够关联证据；后续进入内容评价，不能直接宣布根成功 | 慢A覆盖快B、旧结果、部分加载、空文案与登录并存、AI先到主结果未到；等待耗尽返回证据不足/预算结果 |
| 读取并判断内容 / 读取结果项与字段 | 归属、可见可读范围、字段内容、引用/嵌套及当前必要内容条件；保留学习判断的来源 | 符合内容条件的独立结果才计入根Goal；引用不重复计数 | 相关查询被当结果、AI总结被当已读原始材料、头像当正文图、缺标题被丢弃、无关但含关键词 |
| 扩大已检查范围 / 滚动、翻页、展开 | 采用动作对应方式观察新露出/新批次/展开内容及成员归属，检查查询和筛选是否保持、旧成员是否被虚拟化替换 | 有新且适用证据才增加已检查覆盖；无变化本身形成反馈，不补成新内容 | 滚错容器、滚轮无效、重复项、离屏DOM仍在、动态替换、页码变化但内容未更新；禁止按滚动次数计覆盖 |
| 改变搜索条件 / 切换笔记或用户、选择筛选项 | 选中条件及其作用scope、新响应与查询/条件关联、旧内容是否失效 | 仅在根Goal允许时改变条件；按新条件重验结果，重绑受影响引用 | 改错集合、AI模式与普通结果混用、条件已选中但响应仍旧；既有根内容要求不随操作改写 |
| 恢复执行 / 重试或已确认等效备用入口 | 先核对原错误、effects、安全重试资格与当前前提；动作后按被重试动作的方式重新观察 | 已启用且允许的策略最多执行当前一次；计数/耗尽由controller持有 | 证据不足被误判无效、权限/登录变化、未知副作用、错误仍在；不得盲目固定n次点击 |
| 根评价 / 比较真实结果与要求 | 仅消费显式State中查询/范围、已确认内容、覆盖及其当前适用证据；缺少必要新观测时，先通过已启用的只读技能补证，再进行纯根评价，保留未决错误 | 所有必要条件成立且实际满足度达阈值才结束；子Goal成功不能相加成根成功 | 一个子Goal成功而内容不满足、共享证据重复计分、全部批次不等于全网、证据过期 |

每次执行只有当前一个行为选择和它的必要后验。表中的执行回执核对、实际结果读取和Goal达成检查都属于本步观察反馈；operation-episode的reobserve和verify分别承载采集与检查，不删除verify节点。一次输入的机械键盘原语不作为模型层序；但在依赖该输入的提交前必须先确认输入结果。观察方法由技能提供：可见文字/截图、AX/只读DOM实际值、选中/加载反馈、导航结果或文件/OS证据按动作选用，不强制每例全套；不采cookie、内部store、隐藏请求或fixture内部gold充作用户可感知证据。宿主/范围跨快照变化时需要显式重绑证据，不按AX编号、相同文字或新observationId自动继承。

观察条件是必需下限。模型若未选择足够观察项，harness返回未完成的观察义务，不替模型猜测对象，也不能继续依赖它的动作。观测成功但未变化、观测不足/失败、执行拒绝、发生其他效果、目标达成是不同反馈。静态或未变化页面也要执行必要的读回；超时不是“无效果”的证明。反馈引起只读补证或重新选择时仍受现有预算、权限与effects控制。

### 学习拆分与逐步样本

保留既有四类slot，按责任拆小任务，不另造单一“搜索成功”分类头。固定的观察义务、精确值比较、证据当前性和循环控制不训练。以下学习任务统一infer/train生命周期，尚未有数值wire、样本集、拟合或运行绑定；在可辨输入与独立评价完成前保持未就绪。

| 最小学习任务 | 输入与输出 | 监督与有区分力的反例 |
| --- | --- | --- |
| 当前观察对象选择（当前选择slot的子任务） | 当前子Goal、Action合同的必需事实、已观测候选及许可关系/能力 → 当前读取对象/范围/事实引用或DEFER | teacher确认应观察同一输入宿主或受控结果scope；同一input/按钮类别但相邻用途不同，提交后读旧集合为反例。学习对象关联，不学习“操作后可以不观察” |
| 状态及查询关系（查询关联slot的子任务） | 可读的前后观测、实际动作回执、请求/显示/访问证据及版本关系 → 当前关系/状态判断或unknown/conflict | 输入草稿/真实提交/当前响应分开，旧placeholder与新value、同词旧结果、AI/列表异步、建议项插入、过滤条件变化配对；不能将导航标题单独当关联gold |
| 结果角色与归属（既有内容/对象关系slot） | 当前候选、许可字段与局部关系证据 → 结果、字段、相关查询、引用及其owner判断 | 实际内容和作用独立复核；结果无标题、直播入口、相关查询卡、独立AI栏及引用成员为区分样本，不向L1塞站点身份 |
| 当前反馈解释及候选选择（当前选择slot，组合复用F1/F2原则） | 原请求、真实后验、原始错误/effects及适用历史 → 反馈解释、当前合法候选评分或DEFER | 输入没改变与观察失败分开；已发生effects但未达标与无effects分开；有已确认备用入口时检验当前选择。F1/F2当前仅展开域，不能直接沿其标签/权重宣称搜索已支持 |

一个训练episode保留根/子Goal、阈值、前观测、当前Action预测与实际invocation、所需观察项及所选方法/对象、后观测/缺口、执行错误与观测错误、effects、当前反馈判断、评价和下一步的真实输入。样本只暴露当步以前的事实，teacher及未来达成结果只作标签/评价，不进学生特征。每个被授权使用的步骤都应采集这条反馈链，包括成功、无变化和失败；自动采集与采用仍按model-evolution单元升级DAG，当前未接入，不把本轮Agent记录当自动采样已完成。

单步先训练写入/观察对象与反馈，再训练提交/结果关联，再接内容与扩展范围，最后训练多候选与组合；去掉任何一步的读回应能被独立反例检出。训练不输出整段计划，不监督固定层序或是否继续。根目标满足、预算、持久条件重验与错误隔离仍由现有递归控制器完成。新结果表示先用既有结构、样本和权重学习；只有缺少一类必要事实导致同许可输入对应相反真值，才提出观测/特征缺口，沿模型演进合同处理，不默认重写核心。

实施按上述依赖推进，不在本轮用文档补全冒称行为已运行。每阶段都要求公开consumer驱动真实原生操作，独立记录学生原始选择、实际后验、错误、effects和逐步根评价；合成与真实站点分别报告。独立Reviewer检查评价是否符合人的可感知事实、是否存在错误完成及已知回归，不以fixture响应归属或总准确率替代内容条件。

必要反例至少包括：输入未生效而Enter提交默认词；写对输入但未提交；读取placeholder冒充value；慢A快B；旧结果与AI/主列表不同步；观察失败误判点击无效；查询建议/直播/引用误计结果；筛选后旧证据；无新内容的滚动与虚拟化；根内容不足但子Goal全成功；执行报错且effects未知；预算耗尽。每个反例分别断言当前动作是否允许、需观察什么、真实状态口径、是否允许继续及停止原因。反例定位到具体owner后再补对应gate/红测，不训练一次性脚本掩盖缺口。
