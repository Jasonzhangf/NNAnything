## 2. 权重和职责

- 一个 CLI 领域模型包包含可独立训练/验收的 R、D、E、A 模块；浏览器另有领域包，不共用领域权重。
- R 学对象与条件、来源、目标之间的关系；D 学缺失条件和子目标分解；E 学实际状态对目标的评价；A 学合法动作与参数引用选择。输出形状以四头合同为准，不在此另造词表。
- L1 既有基础模型保留独立职责；OS 回执、字节计数、身份、权限等精确事实由固定执行和观测层提供。L2 学习事实与目标之间的关系，不用预测替代观测。
- 引擎持有真实 State、根 Goal、权限、预算、历史反馈与结束原因。当前满足即停止；未知可在授权和预算内探索；有证据的排除限定作用范围。候选耗尽、缺能力、工程错误、预算/取消分别结束，不伪造满足。
- 首期不按命令建模型、不建学习路由器。先验证领域四头包。后续按语义族拆专家；专家是模型包内的学习单元，不复制推理引擎，不各自保存隐藏权威状态。
- 专家拆分需有实测容量、干扰、时延或独立语义边界依据。跨专家 logits 不直接比较，softmax 不冒充校准概率。

## 3. CLI 命令与编程语义目录

| 阶段 | 语义族 | 命令/固定接口 | 编程目标 |
|---|---|---|---|
| 已有与当前 | 位置、路径、类型、精确文件发现、头尾读取 | pwd/cd、ls/find/rg --files、lstat、head/tail/cat | 找配置、按来源优先级找文件并读 |
| 下一步 | 字面内容搜索、命中位置、上下文读取 | rg/grep 固定参数；后续固定窗口接口 | 找报错文本、调用名称候选、读命中上下文 |
| 后续 | 集合和结构化数据 | sort/uniq/wc/cut、jq | 去重、统计、字段提取与筛选 |
| 后续 | 版本与代码关系 | git status/diff/ls-files/log/show；符号索引接口 | 变更范围、定义/引用、依赖与测试关联 |
| 后续 | 修改与验证 | 固定补丁接口、项目声明的构建/测试入口 | 修改后读回、测试、失败归因与修复 |
| 组合 | 受限管道 | 已注册工具的 typed 数据连接 | 多步搜索、过滤、读取、验证 |

各命令须细分支持的操作与参数，不因列入表就支持全部选项。任意 shell 文本、任意 awk/sed 程序、任意脚本不在首期。文本命中不是符号定义；测试退出零不是任意根目标满足。管道须保留各步回执与数据类型，先训练成员再训练组合关系。

浏览器对应专家候选：对象定位、输入读回、提交与结果归属、展开/导航、跨页检索。先定义新旧结果、查询归属、可观察终态；不得把 CLI 成绩计入浏览器成绩。

## 4. 用案例审查设计

每例必须给出 Goal/阈值、初始已知/未知 State、合法动作、执行前期待、实际回执、R/D/E/A 职责、下一子目标和结束理由。以下是设计示例，不是已生成的验证集：

1. 在 A 后 B 查 config.ini，读尾 8 行：A 完整无匹配后才查 B；B 只有 3 行仍正常满足。检验未知与证伪、优先级和短输出。
2. A 为同名目录，B 为普通文件：异型证伪后换源。若两源均为普通文件，按目标优先级读 A；不能挑更长输出。
3. 请求头 8 行，实际第一次选了尾 8 行：以真实回执评价；证据不足则重新选择，不伪造命令故障，也不总是假定反向读取必错。
4. 在 src 内查字面 FATAL：无命中是正常搜索结果；命中后读上下文。窗口起点必须可辨，旧头尾 E 无该输入不能直接充当窗口评价器。
5. 两个文件均含函数名：只能声明文本候选；有结构证据后才能判断定义或引用。
6. 浏览器输入查询后仍显示旧结果：输入读回成功不满足搜索根目标；需要查询归属和当前结果证据。

逐例增加会改变正确决策的最小对照，检查同一模型输入是否对应冲突监督。不要为了填满类别制造实际命令不会发生的内部错误。

## 6. 数据、训练与评价约束

TRAIN/DEV/VERIFY 按关联来源和组合机制先分区。同模板改名称只验证名称不变性；要声称组合泛化必须留出机制组合。已经暴露的验证转已知回归。G2 已采 L5/L6 异型后次源命中，不能再把该组合当未见验证。

从完整回执派生每个决策时刻的可见前态，未来观测不得回填。teacher 提案需真实证据确认；执行错误、正常无结果、未知与语义不满足分开。每层单训单验，再用模型自己产生的中间状态验证组合，不只用 teacher 强制正确中间态。

后训练继承合格权重与旧 TRAIN 重放。扩输入/输出先测 step-0 迁移影响，再训练；负偏置并不保证新输出不抢旧类别。旧能力退化不得被新增总分掩盖。固定预算内失败就保留结果，分析观测、teacher、表示、优化或组合问题，不自行延长预算追通过。

具体任务书必须预先填写每族验收数值、样本量、硬件和延迟统计方法。顶层不编造统一准确率。必要指标：各头混淆/合法集命中、根假成功、根达成、unknown、纠错率、旧能力退化、动作数、推理 p50/p95、训练耗时与恢复结果。权限和证据真实性是硬边界，不允许用总体准确率抵消。
