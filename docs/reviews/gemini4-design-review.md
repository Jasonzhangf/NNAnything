## 问题与修订

| 首轮问题 | 修订结果 |
| --- | --- |
| 卡片父类/来源子类可能矛盾，几何输入未证明可分全部推广 | 卡片族共享结构支路；解析器维持来源与organic一致性；缺少可辨原语的类别未支持，不把荐读自动当商业推广 |
| within纯DOM后代混淆内嵌帖子，查询与动作图耦合 | owned/subtree显式区分语义归属与DOM范围；纯查询独立返回；queryId关联后续动作，不自动提升可点击祖先 |
| 原始teacher数据与学生输入隔离不够明确，缺测/补负例合同不全 | RawDomNodeEvidence/StudentNodeObservation分离；required缺失失败、optional带可用位；规范范围完整性声明后才自动补负例 |
| 负向支路权重可反转，校准斜率/小样本状态不明确 | 声明参数符号约束；拟合未校准logit；正斜率独立校准，覆盖不足保持未校准，旧校准失效 |
| 来源跨组泄漏与非参数修复缺少同样本回归 | snapshot/post/adAsset关联传递闭包分组；原始现场与规范标签为来源；节点级与查询级跨版本配对，缺测/不可比明确计数 |
| 首期模块偏重，后端接入与原语训练边界不清 | D1缩为core/data/training最小合同；后端D2、批标D3、完整动作监督D4；直接可读原语无需重复训练 |
