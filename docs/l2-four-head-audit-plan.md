## 4. 最小可推进判定

先做两个开发入口证明。这是排障步骤，不代替M1：

1. CLI：受信普通文件、合法权限、read未尝试且回执来源null → 学生选择read → 真实回执 → E单独判定 → 精确根事实确认。再做一次范围错误或可恢复引用更新，检查新子Goal和恢复动作是否来自反馈；非恢复场景准确停止。
2. Browser：显式绑定对象、输入尚未满足 → 学生选择INPUT → 原生写入与读回 → 再按当前真实状态选择SUBMIT/OBSERVE，完成当前查询结果Goal；另测输入无效、旧结果和空结果，不能靠循环固定步骤通过。

训练前必须有各必需动作的有效TRAIN支持，预执行、后执行、失败和缺测不能全部来自同一伴随特征。按原分区补齐6×12 TRAIN、2×12 dev、2×12独立状态；重复相位不增加来源数。额外小型诊断样本单列，不能暗中改正式预算或分母。分区合同明确后才拟合。

T4固定配方继续用两层64、lr=0.15、每头上限240、检查点60/120/180/240。warm-start不重新初始化旧参数。若表示变化需要迁移，先比较迁移前后旧输入输出；不兼容则报告结构变更，设计确认后才训练。本次只准一次有界实验；下一次须由Alice依据新证据给单一假设与可证伪结果。

快速判定失败层：

| 观察 | 下一动作 |
| --- | --- |
| 同一合法输入要求互斥gold，或teacher与真实事实冲突 | 修合同/监督，停止该头及下游拟合 |
| 同一真实状态在采样和runtime编码不同 | 修唯一encoder，不先补权重 |
| 训练正确、开发初态/中间态失败 | 检查实际访问分布与字段依赖，补TRAIN反例；不能直接读最终留出找答案 |
| 合法typed子Goal/候选不能生成，或A选到未接技能 | 修模板/技能接线并红测；不训练模型代替不存在的能力 |
| 表示可辨、数值一致且有效梯度存在，但预算内拟合不足 | 仅结论“本配方未找到合格候选”，检查loss/优化；不宣称MLP无解或预算必然足够 |
| 反复同动作无新事实 | 用原累计retry/budget准确停止，记录所缺可区分观察，不靠新ID刷新进展 |
| 根成功而E错误，或去掉E行为不变 | 分开记录系统与模型成绩，检查E是否被绕过；不拿根成功掩盖评价缺口 |
| 新批提高但旧例退化 | 不采用；诊断数据覆盖/参数干扰，不删除旧知识或旧评价 |

正式门槛仍按原合同：R/E宏F1≥0.95；D/A允许集合命中≥0.95；必需条件与候选召回100%；各域可达≥11/12、受约束不可达6/6、证据不足6/6；受控错误恢复≥5/6；假成功/越权/范围错误证伪为0。总分不抵消强制反例。

## 5. 泛化和消融实验

在既有预算内把每例绑定到失败模式：对象改名/改序不变；同原语不同参数；不同实现来源；已知原语的未见组合；失败后改条件再选路。逐例输出首个错误头、实际动作/观察数、根事实、控制终态和旧知识变化。无真值行保留unassessed，不移出总任务统计来造高分。

只做能回答问题的对照：R输入隔离前后是否减少无关扰动；真实反馈开启/关闭是否提高同类可恢复任务；E输入保留/屏蔽是否改变正确选路；后训练前后是否减少无用动作且旧能力无新增回归。对照参数和来源先在dev定下；不得在独立验证上挑最优结构。小样本“未发现回归”不是全域无回归保证。

本轮不扩Encoder、不生成新自然语言LLM、不预测整个终端文本、不做大规模样本灌入、不自动采用。有限词表扩展只在现有观测、参数与组合无法表达具体新区别时启动，沿原第8节，不为新页面名称新增词项。

## 6. 可借鉴的公开经验

2026-10-24 已读取以下论文公开页面/摘要，借鉴限于设计原则，没有复现论文结果，也不把其保证套到本项目。

- [Ross et al., DAgger, 2011](https://proceedings.mlr.press/v15/ross11a.html)：顺序决策的未来观察由当前策略影响，静态监督分布不等于学生访问分布。本项目采学生在TRAIN环境实际遇到的状态，再离线确认监督并聚合训练；teacher不在正式执行中代答。论文保证有额外假设，不能据此保证本MLP收敛。
- [Battaglia et al., Relational inductive biases, 2018](https://arxiv.org/abs/1806.01261)：结构化实体/关系及共享计算有助于组合泛化。本项目先用按对象对/候选共享的MLP和明确字段边界，不因参考该文就引入完整GNN或Transformer。
- [Rolnick et al., Experience Replay for Continual Learning, 2019](https://arxiv.org/abs/1811.11682)：跨任务经验重放可减少遗忘。本项目从上一权重继续、旧TRAIN重放、独立旧能力回归；重放不是零遗忘证明，采用须以本项目逐例证据决定。

这三项经验支持当前混合方向，不能代替M1/M2。对“有限训练能否面对无限样本”的回答是：有限语义与参数化规则可覆盖大量未见实例，但不能凭有限实验保证任意任务；本轮先验证稳定关系、新组合和两批更新后的保留能力。
