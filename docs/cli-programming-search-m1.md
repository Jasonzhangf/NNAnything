# 编程搜索M1：隔离沙盒、反馈纠错与重复任务提效

2026-10-24设计，尚未实现本切片或训练新候选。用户短期目标是自主使用已知CLI能力完成编程搜索，先证明可纠错、可达，再评多次类似任务提效。Carol为CLI实现owner，Jenny负责共享依赖，Alice负责设计与疑难分析。

## 1. 目标与范围

编程任务按搜索、计划、修改、测试推进。本M1仅搜索：在授权的项目目录内寻找文件名和内容字符串匹配，输出带真实来源的位置，作为后续计划/修改的输入。调用者给根Goal、查询、允许根范围与预算，不给正确文件路径、head、子Goal顺序或候选答案。

首轮支持精确名称/后缀与UTF-8字面字符串，不引入自然语言解析、正则、模糊搜索、AST定义/引用推断、任意shell文本生成。声明式查询示例是“src后代、后缀.ts、内容包含requestId、取得任一当前命中”。符号名字符串命中不能冒称符号定义或引用。

现有directory.list、entry.inspect、file.read、路径操作与共享cli.command-policy.v1复用；本轮不需要通过接入rg/find才能证明搜索目标。若后续选择注册新命令，先固定typed调用/机器证据合同，不借新命令建立第二选择器。

## 2. 四元素与请求语义

| 元素 | 定义 |
| --- | --- |
| Goal | file.property.directory.entries的范围与名称/后缀谓词，及file.property.content.bytes的UTF-8字面包含谓词；组合必须对当前对象验证两个谓词 |
| satisfactionThreshold | 二元根事实：满足100、已实际证明不满足0、证据不足null。首选失败不改变根Goal或阈值 |
| State | 当前目录待查集合、已观察覆盖、受信对象引用、已读范围与匹配、逐步错误/观察、具名失败先验、剩余预算、真实checkpoint。控制状态沿recursive-goal合同显式持有 |
| Action | 从已启用已知技能选择当前一步：列举、核验、读取；纯字面比较与解码不派OS动作。动作后观察，再决定下一步 |

领域owner在独立Plan中将此语义绑定到最小typed请求/结果，不创建零散Goal词表或通用shell接口。未知谓词准确unsupported，不把模型分数当内容证据。

必须区分两种范围：

- `one`：存在一个合法真实命中即可完成，不要求读完所有候选。可用于验证更好候选排序带来的提效。
- `all`：必须完成声明范围的覆盖才可声称完整结果。局部命中可保留，但未完成遍历/读取仍是partial，不能靠少读文件伪造效率。

负向结论也需覆盖：一个文件完整读取无该串，只排除该文件在该身份/观测时点下的该查询；不能排除整个目录。跨分块匹配不得漏掉块边界；UTF-8不完整/非法、二进制、短读、预算截断分别报告，不强行补文本。结果应含受信fileRef、字节跨度及约定的行列，行列语义/换行规则由Plan固定。

## 3. 两套沙盒

训练与测试复用同一沙盒接口，但使用不同根、session、配方和来源家族。fixture创建权限由setup owner持有，交给搜索agent的会话只有本任务所需只读effects。每个episode从fresh配方开始，结束验证内容/目录项不被搜索动作改变；清理仅由owner删除自有场景。

| 环境 | 输入与用途 | 禁止混入 |
| --- | --- | --- |
| 训练沙盒 | 合成小型编程项目；可观测成功/失败轨迹、teacher与gold、隔离拟合候选 | 测试家族实现、真实用户代码树、后验正确路径进入t0 |
| 开发沙盒 | 固定配方，只作问题定位与预算内模型选择 | 宣称全新资格来源 |
| 测试CLI沙盒 | 独立作者/独立实现家族、新命名/嵌套/内容；真实执行已注册CLI语义并由独立oracle核对结果 | 训练配方、fitter、gold入口、预先填正确文件ref |

现有filesystem-sandbox是固定调用与引用/路径授权的应用层隔离，不等于任意进程的OS级隔离。M1仅运行受审已知helper，不执行项目脚本、不联网、不安装依赖、不调用未知程序。若要开放任意CLI或不可信程序，须另有进程隔离设计；不能以函数名sandbox冒称已实现。

沙盒项目应包含src/tests/docs等目录、干扰文件与重复名称；内容与路径名称可以帮助排序，但不能成为固定正确答案。训练/开发/测试按实现配方先分区，再生成任务和变体，关联episode不跨区。

## 4. 首个最小实验

在一个小项目中，用根Goal“src内任一.ts文件包含requestId”开跑：设置至少一个符合文件条件但无内容命中的干扰项，以及一个真实命中项。先让合法策略选择干扰项，真实读取确认无命中，再从更新后的State选择另一候选，最终核验命中位置与根Goal。

必须得到两条公开轨迹：正常首选成功；首选未命中后恢复成功。故意首选由测试策略资源明确注入，单列为恢复能力测试，不算模型自然选择成绩。oracle只做独立评价，不能替学生指出下一正确路径。

首次实验成立后再扩深层目录、多个同名文件、文件条件与内容条件分别命中但不在同一对象、无命中、partial、取消/预算与对象替换。训练不先铺满所有编程活动。

## 5. 推理与纠错责任

复用recursive-goal 3N2E、cli-file-property 6N5E及现有search/read组合。现有受影响DAG先核完整、闭合与SESE；需要新组合责任图由CLI owner按DAGpipe规范设计，不能手写第二循环。一次技能的语义、调用、后验和账本应一致，不为固定测试预算隐藏其他操作。

| 真实反馈 | 合法更新与下一动作 | 不得推断 |
| --- | --- | --- |
| 当前文件完整读且无字面命中 | 标本对象/查询已检查，选其他候选 | 整个目录无结果 |
| 名称相似但后缀/范围/类型不符 | 排除该候选对当前谓词的资格 | 其他同名文件也不符 |
| 目录列举partial | 保留已知项与未覆盖范围；只按既有合同允许的证据推进，否则停止unknown | complete/not_found |
| 文件变更或引用失效 | 保留stale，按明确授权重新观察/绑定 | 静默沿用旧bytes或把换对象当同一对象 |
| 读取拒绝/执行错误 | 记录原errno与作用范围；若Goal仍有合法替代对象可选，则尝试次选 | 缺权限自动提权、吞错、对整个语义判失败 |
| 无可用合法技能/预算耗尽 | 准确停止，保留根事实与部分结果 | 换策略重置budget或假报根满足 |

失败反馈只更新有证据支持的候选/条件/版本范围。checkpoint不撤销真实OS副作用，不复活旧授权或失效引用。可恢复路径与安全停止路径都必须闭合。

## 6. 训练责任

基础字面比较、UTF-8规则、目录/范围覆盖与控制层序保持确定性。共享命令head继续由唯一cli.command-policy.v1负责。搜索新增学习应放在明确的候选/下一合法技能偏好单元，复用统一infer/train接口；不得为“必须训练”重拟合已满分原子policy。

先建固定规则baseline和可重复执行的成功/恢复路径，再判断哪个选择有可辨输入与优化空间。若固定语义与现有selector足够，诚实交付规则能力；学习阶段至少要证明一个候选排序/失败利用选择能使类似任务成本改善。控制器决定是否继续、计数与预算，不训练层序。

使用轨迹按model-evolution的t0/t1/t2边界收集：当步学生输入/候选/输出、实际调用、真实后验、反馈归因、最终根事实、成本。某文件无命中可成为该文件与该查询的真实反馈，不自动成为名称/内容语义的普遍负例；未执行的备选只有teacher建议，没有实际成功奖励。

训练前检查输入/gold冲突、负监督是否进loss、可训练地址与梯度、有限可表达性。独立Plan固定一轮预算与停止条件；配方失败须定位，不自行加epoch。保存候选、新进程回载；当前权重与候选隔离，沿既有采用合同，不因当前任务碰巧成功自动更新。

## 7. 路径评估与效率

策略首选允许出错。硬失败是错误反馈未被识别、无依据恢复、相同已证失败无限重复、越权/副作用、错误not_found或假成功，以及在声明预算内本来存在合法可达路径却恢复失败。

| 指标 | 分母/含义 |
| --- | --- |
| 首次命中率 | 首个实际搜索候选即完成Goal/可评价任务；仅作策略指标 |
| 预算内根成功率 | 真实达成根Goal/具备合法成功路径的测试任务 |
| 失败后恢复率 | 首次实际失败后根成功/有合法替代路径且发生失败的任务 |
| 准确停止率 | 正确not_found或unknown/不可达、覆盖不足、拒绝等对应任务；分状态报告 |
| 重复错误率 | 在相关证据/身份/查询未变时再次选择已证失败候选的次数/恢复决策次数 |
| 调用/观察/读取量 | 每个任务的真实CLI调用数、观察数、读取字节、重复读取；one与all分开 |
| 耗时 | 同环境配对中位数与尾部数据；不能靠一次wall time变快证明学习 |

第一阶段要求固定必需任务的最终根事实、恢复与停止均符合合同，不要求首选全对。学习提效阶段要求同一批新任务上，候选相对baseline最终成功/准确停止不退化，至少一项预声明路径成本改善，并保留逐例退化。不能用少查文件降低all覆盖来换成本。

三种对照分开：冷启动固定baseline；同一任务/同一内容缓存；隔离真实拟合并回载后在新任务上的学习迁移。只有第三种支持“多次类似任务越做越高效”的训练结论；同任务缓存可以有用，但不算学会泛化。

## 8. 分阶段任务与停点

| 阶段 | 交付与验收 | 停止/失败处理 |
| --- | --- | --- |
| P0 沙盒与能力盘点 | 训练/开发/测试fresh根与来源隔离；现有固定CLI真实运行、只读effects、无用户文件副作用 | 隔离或可观察性不成立，先修对应owner，不开训 |
| P1 搜索规则基线 | one精确文件/内容组合的正常与干扰首选恢复两轨迹；真实字节/位置/根评价 | 无合法路径或反馈不能区分结果，先补语义/观察，不训猜测 |
| P2 有界搜索与恢复 | all覆盖、嵌套、同名、partial、错误、stale、取消/预算；不重复已证失败 | 失败分支不闭合，修DAG/状态/权限，不能只增预算 |
| P3 单元训练与提效 | 明确可训练选择，真实拟合/保存/新进程回载；独立来源新任务路径配对 | 无独立成本收益就如实未证提效，不扩大采用；恢复失败先查反馈而非只调首选分类 |

探索先按P0→P1推进；P1成功才扩大P2；P3只在有真实选择空间、可辨输入和路径成本差时启动。测试至少覆盖：正常命中、错误首选后命中、one/all差异、完整无命中、同名跨目录、范围逃逸、symlink、partial/读错、chunk边界、对象替换、预算续跑计数、重复任务提效。实际数量和来源配方由独立Plan按最小充分失败模式确定，不用海量同构样本冒充分母。

完整可交付milestone完成作者验收后做一次独立Review，审核原始路径、oracle前提、反馈范围、成功/恢复/效率指标。保留S06及原有UNVERIFIED，不把本切片通过扩为基础全完成。未授权修改、运行项目测试和未知CLI适配继续后置。
