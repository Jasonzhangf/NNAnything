# G1 有限读取泛化验证与下一实验（Alice 裁决）

2026-10-26。用户明确：主交付是泛化可行性结论，得到结论后全面设计数据和训练。生产原语不是泛化证据的前置条件；已启动原语继续，由Jenny集成，不占用泛化决策主线。

## 当前可支持结论

有限读取语义在不同真实文件、head/tail、多个N、短/空/无末尾LF及不同初始状态上可复用；已有D/E/A可进入真实循环纠错。正式consumer的57/57是开发集成验证，不是新的独立泛化成绩。此前独立来源80 episode支持其限定家族行为，但仍是有限分布。不能推出开放CLI或新关系组合已学会。

D当前仅5种有效投影，扩大同形文件不增加关系组合难度。现有证据支持开始完整数据路线设计及下一有界训练实验；不支持无门槛全面生成并投入大规模训练。后续必须报告哪些轴已覆盖，不能用一个总体准确率宣称无限泛化。

## 两个最小决策实验，不等生产集成

G1 固定模型泛化：保留D/E/A与输入不变，在新的独立生成器和目录中运行真实公开引擎。沿已支持单目录严格名称regular读取，分别统计：路径/文件表示变化，N在既有训练范围内未出现值，长度与方向的交叉组合，已有错误读回恢复。先审计既有训练/DEV使用N与场景，再定义留出，不能把N2/5/11或已用文件族重复称未见。任何已看过失败转DEV后，新独立验证必须更换来源。训练区间外N单列探测，不当作固定范围必过门槛。

G2 组合与增量泛化：扩展为两个显式已授权候选目录的精确regular目标；根要求不变，候选条件增加。用真实readdir/lstat/head/tail形成证据；只按用户明确目标的源优先级消歧，不能把任意同名项作为正确答案。训练、开发、独立验证按场景生成规则/来源分组后生成。必须同时含首源命中、首源无匹配而次源命中、同名异型、双方无匹配，以及初始证据已具备的交叉组合。R负责目标与候选的关系，D负责缺失条件/候选路径，E负责结果满足，A负责当前动作。未知与无匹配分开。

G2不是本文件直接训练授权：Alice先给出确切输入列、标签与teacher依据、旧权重扩展映射、参数配方和预算。旧训练重放与新训练联合，独立验证不得进入拟合/选参。不得将重训新网络冒充后训练；确有维度扩展时按名保持旧子网络功能并验迁移前后等价。

## 数据设计立即开始的范围

按CLI路线S0-S12和浏览器既有目标分别列语义族、对象关系、前置条件、动作、可观测后果、正负/未知反馈、后续goal、分区来源、oracle、真实采集方法。仅当前读取及下一搜索组合进入详细可执行样本规格；其余先完整概要覆盖，避免先生成大量无法训练的样本。

准入分阶段：G1通过支持当前有限语义的数据泛化；G2独立组合留出通过且旧能力无退化支持扩大对应语义族训练。任何结果不要求生产sandbox已合并，不要求TS复制PyTorch优化器，不自动要求CLI/浏览器同时完成后才推进一个已验证领域。
