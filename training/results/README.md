# 训练评估与新旧比较报告 (training/results/)

本目录存放模型拟合、校准状态评估以及新旧版本模型逐例比较的结构化报告产物。

## 1. 职责与内容规范

1. **引用权重而非复制权重**：本目录下的评估报告必须显式引用 `training/weights/` 中的具体 `profileId` 或文件名，**严禁在本目录重复冗余存放权重参数拷贝**。
2. **逐例诚实评估**：
   - 针对留出验证集或回归集，报告必须逐例输出判定结果：`fixed`（已修复）、`regressed`（退化）、`retained`（保持正确）、`unresolved`（仍未解决）、`unassessed`（证据不足无法判定）；
   - 严禁通过汇总 loss 下降或平均准确率掩盖关键场景下的回归用例；
   - 缺测或未知状态明确记录为 `unassessed`，严禁直接充当负例计算假高分。
3. **校准状态声明**：报告必须真实反映校准充分性，在独立覆盖样本不足时，必须明确标记为 `uncalibrated` 或 `development-only`。

## 2. Git 忽略

本目录下生成的评估报告（`*.json`、`*.md` 等）均受 `.gitignore` 保护，仅保留本 `README.md`。
